## 四、结论与部署建议

### 4.1 AWQ 量化覆盖总结

| 系列 | 官方 AWQ 覆盖情况 | 建议 |
|------|------------------|------|
| **Qwen2.5-VL** | ✅ 全档位（3B/7B/32B/72B）官方 AWQ | **优先使用**，显存占用降低约 50-60% |
| **Qwen2-VL** | ✅ 全档位官方 AWQ | 同上 |
| **InternVL2.5** | ✅ 4B/8B/26B/38B/78B 官方 AWQ；1B/2B 无 | 小模型（1B/2B）直接用 FP16，显存足够 |

| **InternVL3.5** | ❌ 全系列无 AWQ | 需自行量化或等待官方发布 |
| **Qwen3.5** | ❌ 全系列无官方 AWQ | 有第三方 `tclf90` AWQ（27B），其余需自行量化 |
| **Qwen3-VL** | ❌ 全系列无官方 AWQ | 有第三方 `tclf90` AWQ（32B/235B） |
| **MiniCPM-V** | ✅ 4.5/o-4.5 有官方 AWQ；2.5/2.6 仅有 int4 | 端侧优先用 int4 版本 |
| **LLaVA-OneVision** | ❌ 无 | 需自行量化 |
| **SmolVLM** | ❌ 无 | 模型本身很小（256M-2B），FP16 即可 |
| **Phi-3/3.5 Vision** | ❌ 无 | 需从 HF 下载后自行量化 |
| **Molmo** | ❌ 无 | 需从 HF 下载后自行量化 |
